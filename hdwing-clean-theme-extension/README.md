# hdchina清爽主题 · Chrome 扩展版（主力）

HDWinG 全站清爽主题：**白底、蓝色导航条、置顶淡蓝行、清晰网格**，候选区/求种区/字幕页/论坛/控制面板同样适配。当前版本 **v2.34.1**。

这是主力版本。由同名油猴脚本迁移而来，主题效果一致，但**稳定性更好**：首帧防闪 CSS 由 manifest 在页面解析前注入（油猴的 JS 时机做不到），且各页面的插色清理全部改为 CSS 常驻规则，不再依赖 JS 执行时机，杜绝偶发失效。

## 一、安装

本地扩展（未上架商店），通过开发者模式加载：

1. Chrome 地址栏输入 `chrome://extensions`
2. 打开右上角 **开发者模式**
3. 点 **加载已解压的扩展程序**，选中 `hdwing-clean-theme-extension` 文件夹
4. 工具栏出现蓝底白条图标即安装成功；打开 `https://hdwing.org/torrents.php` 查看效果

> Edge 等 Chromium 内核浏览器同样支持，路径为 `edge://extensions` 等。

**⚠️ 与油猴版二选一**：请先在 Tampermonkey 里把「hdchina清爽主题」设为**禁用**或删除，不要两个同时开——会叠加两层 CSS，产生无谓的 `!important` 竞争。设置项共用同一套 localStorage key，切换不丢配置。

## 二、日常使用

点击工具栏**蓝底白条图标**弹出设置面板：

| 开关 | 作用 | 默认 |
|---|---|---|
| 主题总开关 | 关闭后恢复 HDWinG 原生界面 | 开 |
| 紧凑行距 | 种子列表行高 | 开 |
| 表头吸顶 | 滚动时固定表头 | 关 |
| 淡入防抖 | 表格加载时轻微淡入（纯 CSS，不会藏表格） | 开 |

切换开关后对应的 HDWinG 标签页自动刷新。设置存在 HDWinG 站点的 `localStorage`（`ssdtheme_*`），清除网站数据会重置。

## 三、更新（重点）

本地扩展**不会自动更新**。检测到新版本时页面右下角会弹出提示，点击可打开项目 Releases 页。手动更新步骤：

1. 从项目仓库下载/拉取最新代码，覆盖本地 `hdwing-clean-theme-extension` 文件夹里的文件
2. 打开 `chrome://extensions`，点这个扩展卡片上的**重新加载**按钮（圆形箭头图标）
3. 刷新 HDWinG 页面

> 更新时只需覆盖文件，`localStorage` 里的开关设置不会丢。

## 四、为什么比油猴版稳

| 项目 | 油猴版 | 扩展版（主力） |
|---|---|---|
| 首帧防闪 | `document-start` JS 注入，页面解析后才生效，可能先闪一下灰蓝 | manifest 声明式 CSS，**页面解析前**注入，灰蓝没有机会被绘制 |
| 插色清理 | 部分靠 JS 扫描背景色逐行压白，时序不稳会偶发漏网 | 全部改为 CSS 常驻规则，注入即永久生效，零时序依赖 |
| DOM 未就绪 | 油猴执行时机较晚，一般 body 已存在 | `document_start` 时 body 可能为 null，代码已加兜底处理 |
| 菜单 | `GM_registerMenuCommand` 注入到页面菜单 | 工具栏 popup 面板 |
| 更新 | 靠 `@updateURL` + Tampermonkey 自动检查 | 本地扩展需手动重新加载（有页面内提示） |
| 主题效果 / 配色 / 各页适配 | —— | **完全一致** |

## 五、常见问题

**Q：工具栏没看到图标？**
点 `chrome://extensions` 里的拼图块图标，把这个扩展 pin 到工具栏。

**Q：某个页面样式不对？**
先看是不是油猴版还开着（两个同时开会冲突）。确认只有一个版本后仍有问题，去项目仓库提 issue 并附截图。

**Q：想临时看原生界面？**
popup 里关掉「主题总开关」即可，不用禁用扩展。

**Q：能上架 Chrome 商店自动更新吗？**
可以但需要开发者账号和审核；本项目是自用主题，暂不上架，采用手动更新。

## 六、文件结构

```
hdwing-clean-theme-extension/
├── manifest.json      扩展清单（MV3）：content script、popup、权限、图标
├── flash-guard.css    首帧防闪守卫（页面解析前注入的纯色规则）
├── content.js         主题主体：CSS 生成 + DOM 修复 + 更新检测
├── popup.html         工具栏设置面板
├── popup.js           popup 逻辑（读写页面 localStorage）
└── icon16/32/48/128.png  扩展图标
```
