# hdchina清爽主题

给 **HDWinG（hdwing.org）** 用的清爽主题 Chrome 扩展，把 HDWinG 原本灰蓝厚重的一整套界面，换成 SpringSunday（SSD）那种**白底、蓝纸条、清晰网格、紧凑列表**的清爽风格。

全站生效，不改站点任何文件，关掉扩展即恢复原样。

- 当前版本：**v2.39.0**
- 适用站点：`https://hdwing.org/*`（http 亦可）
- 形态：Chrome / Edge 等 Chromium 内核浏览器的本地扩展（未上架商店）
- 安装包：`hdwing-clean-theme-extension.zip`（或直接用 `hdwing-clean-theme-extension/` 目录）

> 早期本主题以油猴（Tampermonkey）脚本形态开发，**自 v2.39 起脚本已停止维护并从仓库移除**，只保留扩展版。原因见文末「为什么是扩展而不是脚本」。

## 二、安装

### 方式 A：加载已解压的扩展（推荐，方便更新）

1. 下载本仓库（`git clone` 或右上角 **Code → Download ZIP** 后解压）
2. Chrome 地址栏输入 `chrome://extensions`
3. 打开右上角 **开发者模式**
4. 点 **加载已解压的扩展程序**，选中 `hdwing-clean-theme-extension` 文件夹
5. 工具栏出现蓝底白条图标即成功；打开 `https://hdwing.org/torrents.php` 查看效果

> Edge 等 Chromium 内核浏览器同理，路径为 `edge://extensions`。

### 方式 B：用打包好的 zip

`hdwing-clean-theme-extension.zip` 解压后，按方式 A 第 2–4 步加载解压出的文件夹。

### 安装后确认

按 `F12` → Console，看到下面这行即为生效：

```
[hdchina清爽主题·扩展版 v2.39.0] 投票列修复: … | 灰底清除: … | 标题框恢复: … | 分页修复: …
```

> ⚠️ 如果你以前装过同名**油猴脚本**，请到 Tampermonkey 面板把它**禁用或删除**——两个同时开等于两层 CSS 互相覆盖，会制造闪烁和无谓的 `!important` 竞争。

## 三、使用

点击工具栏**蓝底白条图标**弹出设置面板：

| 开关 | 作用 | 默认 |
|---|---|---|
| 主题总开关 | 关闭后恢复 HDWinG 原生界面 | 开 |
| 紧凑行距 | 种子列表行高。觉得太挤就关掉 | 开 |
| 表头吸顶 | 滚动时是否固定表头（贴近 SSD 原生） | 关 |
| 淡入防抖 | 表格加载时轻微淡入（纯 CSS，不会先藏表格） | 开 |

切换开关后，已打开的 HDWinG 标签页会自动刷新。设置存在站点 `localStorage`（`ssdtheme_*`），清除网站数据会重置，更新扩展不会丢。

### 更新

本地扩展**不会自动更新**。检测到新版本时页面右下角会弹提示：

1. `git pull` 或重新下载覆盖 `hdwing-clean-theme-extension/` 里的文件
2. `chrome://extensions` 卡片上点 **重新加载**（圆形箭头）
3. 刷新 HDWinG 页面

### 自定义配色

配色集中在 `hdwing-clean-theme-extension/content.js` 的配色对象里（十六进制色值），改完保存后在扩展页点「重新加载」：

```js
var C = {
    pageBg:      '#ffffff',  // 页面背景
    innerBorder: '#a5b0bc',  // 行分隔线（调浅如 #c3cbd4 会更柔和）
    headerBg:    '#e9e9e9',  // 表头底色
    navBg:       '#4a7ab8',  // 导航条蓝色（换成 #2f5e96 更深）
    link:        '#1a5eab',  // 普通链接蓝
    titleLink:   '#164a84',  // 种子标题深蓝
    stripe:      '#d6e6f8',  // 置顶行淡蓝
    freeColor:   '#008000',  // Free 标记绿字
    // …
};
```

- **想让导航更亮/更深**：改 `navBg`
- **觉得表格线太重**：把 `innerBorder` 从 `#a5b0bc` 调到 `#c3cbd4`
- **想让置顶行更明显/更淡**：改 `stripe`

## 五、实现思路（技术说明）

扩展同时用了三种手段：

1. **声明式 CSS 预注入（首帧防闪的关键）**
   `manifest.json` 里 `content_scripts` 声明 `flash-guard.css` + `run_at: document_start`，浏览器在**页面解析之前**就把 CSS 注入。原主题的灰蓝底在被绘制之前就已被压掉，所以切换页面、刷新都看不到"先灰一下再变白"。这一点油猴脚本做不到——脚本执行时机永远晚于首帧。

2. **CSS 覆盖主题**
   按 HDWinG 原生 CSS 的实际选择器逐条对位（`.torrent_list`、`table.table_forums`、`.details_box`、`ul.menu li a`、`.index_new` 等），用 `!important` 覆盖颜色、边框、间距；样式表在解析早期被移到文档末尾，保证层叠顺序最后，不被原生样式反压制。各页面的插色清理一律写成 CSS 常驻规则，注入即永久生效，零时序依赖。

3. **灰蓝区间判定（JS 兜底）**
   原主题的灰蓝家族有 #738ba8 / #b9c5d3 / #b1bdcb / #cdd7e3 / #738bb0 / #a5b1c0 等多个近似色，且大量写在行内样式 / `bgcolor` 属性上。脚本不穷举色值，改用区间判定（蓝 ≥ 绿 ≥ 红、亮度中等、蓝红差 8~90），凡命中即压白；配合 `MutationObserver` 监听后续插入的节点（翻页、展开、AJAX 内容），插入后下一帧即刻清理。

**豁免名单**（不会被清白）：导航条自身、站点 Logo、捐赠进度条、种子列表的置顶行淡蓝。

**分页当前页判定**：不走 DOM 猜结构，而是读 URL 的 `?page=` 参数，再用分页链接样本投票校准起始基数（0/1）与每页条数，算出当前页码段文本，只给文本恰好等于该段的按钮上深蓝底——所以不会出现"在 1401–1500 页却把 1–100 染蓝"。

## 六、常见问题

**Q：装好了但页面没变？**
1. `chrome://extensions` 里确认扩展是启用状态、版本号是 v2.39.0；
2. 确认扩展卡片上没有"错误"按钮（有的话点开看报错）；
3. 按 `F12` → Console 看有没有 `[hdchina清爽主题·扩展版]` 日志和红色报错。

**Q：切换页面时闪一下灰？**
扩展是页面解析前注入 CSS，理论上不会。若仍闪，先确认**油猴脚本是否还开着**（两个同时跑会互相覆盖）。确认只有一个后再复现，把页面地址告诉我。

**Q：某个页面还有灰蓝块 / 某个表格样式没跟上？**
把页面地址 + 截图发我，或按 `F12` 选中该元素把 `class` 告诉我，可精确定位补规则。

**Q：想完全恢复原版界面？**
点图标在 popup 里关掉「主题总开关」即可，不用禁用扩展。

**Q：想上架 Chrome 商店自动更新？**
需要开发者账号和审核；本主题是自用，暂不上架，采用手动更新。

## 七、为什么是扩展而不是脚本

早期油猴脚本版本为了消除"切换版面先闪一下原主题灰蓝"，连续试过 CSS 隐藏、行内 `visibility:hidden`、`documentElement` 未就绪重试、双 `rAF` 放行等多种方案，都无法彻底根治——因为**油猴脚本的执行时机本身晚于浏览器首次绘制**，防闪代码再早也是在页面已经画出来之后才跑。

扩展版靠 `manifest` 声明式注入 CSS，注入发生在页面解析之前，这个问题从机制上就不存在。因此项目从 v2.39 起收敛为单一扩展版，脚本版本不再维护。
