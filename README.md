# hdchina清爽主题

给 **HDWinG（hdwing.org）** 用的油猴（Tampermonkey）主题脚本，把 HDWinG 原本灰蓝厚重的一整套界面，换成 SpringSunday（SSD）那种**白底、蓝纸条、清晰网格、紧凑列表**的清爽风格。

全站生效，不需要改站点任何文件，关掉脚本即恢复原样。

- 脚本文件：`hdwing-ssd-theme.user.js`
- 当前版本：**v2.39.0**
- 适用站点：`https://hdwing.org/*`（http 亦可）
- 一键安装：[点此安装 / 更新脚本](https://raw.githubusercontent.com/ljp801005-tech/hdwing-clean-theme/main/hdwing-ssd-theme.user.js)（需先装好 Tampermonkey，打开后会自动弹出安装页）

## 二、安装

### 1. 安装 Tampermonkey

浏览器扩展商店搜索 **Tampermonkey**（油猴）安装，Chrome / Edge / Firefox / Safari 均可。

### 2. 安装脚本

**方式 A（推荐）**：把本目录的 `hdwing-ssd-theme.user.js` 直接拖进浏览器窗口，Tampermonkey 会弹出安装页，点「安装」。

**方式 B**：点 Tampermonkey 图标 → 管理面板 → 「+」新建脚本 → 全选删除模板内容 → 粘贴脚本全文 → `Ctrl/Cmd + S` 保存。

### 3. 确认生效

打开 `https://hdwing.org/torrents.php`，页面应变成白底蓝条。也可按 `F12` → Console，看到下面这行即为生效：

```
[hdchina清爽主题 v2.39] 投票列修复: … | 灰底清除: … | 标题框恢复: … | 分页修复: …
```

## 三、使用

### 菜单开关

点 Tampermonkey 图标，脚本下方有四个开关（点击后页面自动刷新）：

| 菜单项 | 作用 |
|---|---|
| ✔ SSD主题：已启用 / ✘ SSD主题：已关闭 | 整站主题总开关，关掉即恢复原生界面 |
| 📦 紧凑行距：开 / 关 | 种子列表行高。觉得太挤就关掉，恢复宽松行距 |
| 📌 表头吸顶：开 / 关 | 滚动时表头是否固定在顶部（默认关，贴近 SSD 原生） |
| ✨ 淡入防抖：开 / 关 | 种子行分批加载时先隐藏表格、稳定后整体淡入，消除加载抖动（默认开） |
| 🔄 检查脚本更新（立即） | 立即向 GitHub 检查是否有新版本（不受每日一次限制） |
| ⬆ 有新版本 x.x.x · 点击更新 | 仅当检测到新版本时出现，点击打开安装/更新页 |

### 自动更新（每日首次打开自动检查）

v2.33 起内置自动更新支持，**双保险**机制：

**① 脚本已声明更新源**（`@updateURL` / `@downloadURL` 均指向 GitHub raw 安装链接）。剩下只需在 Tampermonkey 里开一次设置，之后就全自动：

1. 点 Tampermonkey 图标 → **管理面板 / 仪表盘** → **设置** 标签
2. 配置模式选 **高级（Advanced）**（否则看不到下面选项）
3. 找到「**脚本更新 / Check for userscript updates**」，检查频率选 **每天（Daily）** 或 **每次启动浏览器时（On browser start）** —— 这就对应"每日第一次打开浏览器时检测"
4. 更新方式选 **静默更新（Silent）**，检测到新版会自动下载安装、不弹窗打扰

配好后：每天你第一次打开浏览器，Tampermonkey 就会回 GitHub 比对 `@version`，有新版自动装上。

**② 脚本自带每日检测 + 桌面通知**：即使上面的静默更新没配好，脚本自己也会在每天首次访问站点时检测一次版本，发现新版就弹系统通知（点通知直接打开更新页），菜单里也会多出「⬆ 有新版本」项。

> ⚠️ 两个前提：
> - **必须从 raw 链接安装**（本 README 顶部的一键安装地址），不能下载 `.user.js` 文件后拖进油猴——文件安装没有更新源，永远不会自动更新。
> - 首次触发脚本内检测时，浏览器可能弹出"允许脚本访问远程地址"的授权提示，选**允许**即可。

### 自定义配色

脚本开头有一段「配色区」，改颜色后保存即可（十六进制色值）：

```js
var C = {
    pageBg:      '#ffffff',  // 页面背景
    innerBorder: '#a5b0bc',  // 行分隔线（调浅如 #c3cbd4 会更柔和）
    headerBg:    '#e9e9e9',  // 表头底色
    navBg:       '#4a7ab8',  // 导航条蓝色（换成 #2f5e96 更深）
    link:        '#1a5eab',  // 普通链接蓝
    titleLink:   '#164a84',  // 种子标题深蓝
    stripe:      '#d6e6f8',  // 置顶行淡蓝
    freeColor:   '#008000',  // Free 标记绿字
    // …
};
```

常见调整：

- **想让导航更亮/更深**：改 `navBg`
- **觉得表格线太重**：把 `innerBorder` 从 `#a5b0bc` 调到 `#c3cbd4`
- **想让置顶行更明显/更淡**：改 `stripe` 的值（当前淡蓝 `#d6e6f8`）

## 五、实现思路（技术说明）

脚本做了三件事，配合使用：

1. **CSS 覆盖**：按 HDWinG 原生 CSS 的实际选择器逐条对位（`.torrent_list`、`table.table_forums`、`.details_box`、`ul.menu li a`、`.index_new` 等），用 `!important` 覆盖颜色、边框、间距；注入时机为 `document-start`，并在页面加载早期把样式表移到文档末尾，保证 CSS 层叠顺序最后，避免被原生样式反压制。

2. **灰蓝区间判定（JS 兜底）**：HDWinG 的灰蓝家族有 #738ba8 / #b9c5d3 / #b1bdcb / #cdd7e3 / #738bb0 / #a5b1c0 等多个近似色，脚本不穷举色值，改用区间判定（蓝 ≥ 绿 ≥ 红、亮度中等、蓝红差 8~90），凡命中即压白。这样站点新页面、新结构也能自动适配。

3. **DOM 监听**：`MutationObserver` 监听后续插入的节点（翻页、展开、AJAX 内容），插入后下一帧即刻清理，不会出现"先灰一下再变白"的闪烁。

**豁免名单**（不会被清白）：导航条自身、站点 Logo、捐赠进度条、种子列表的置顶行淡蓝。

## 六、常见问题

**Q：安装了但页面没变？**
1. 看 Tampermonkey 管理面板里脚本是否「已启用」；
2. 看脚本版本是否为目标版本（覆盖安装有时会留下旧条目，建议先删旧脚本再装）；
3. 按 `F12` → Console 看有没有 `[hdchina清爽主题]` 日志和红色报错。

**Q：切换页面时闪一下？**
v2.18 已处理（样式提前注入 + 文档末尾定位 + 早期多轮补扫 + DOM 监听）。如果仍偶尔闪 1 帧，属于浏览器首帧渲染顺序限制。

**Q：某个页面还有灰蓝块 / 某个表格样式没跟上？**
把该页地址 + 截图发我，或按 `F12` 选中那个元素，把它的 `class` 名告诉我，可精确定位补规则。

**Q：想完全恢复原版界面？**
Tampermonkey 菜单点「SSD主题：已启用」→ 关闭，页面刷新即恢复原生皮肤；或直接禁用脚本。

**Q：安装新版会不会出现两个脚本？**
`@name` 与 `@namespace` 都一致时是覆盖更新；若曾改过名，建议先在管理面板删掉旧条目再安装。
